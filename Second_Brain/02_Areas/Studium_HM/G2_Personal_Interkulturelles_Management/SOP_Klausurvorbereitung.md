# G2 Personal/IKM — SOP Klausurvorbereitung

> Lernmethodik: [[03_Resources/Lernmethoden_Referenz|Lernmethoden_Referenz]]. Hier nur das G2-Spezifische.

## 1. Themenreihenfolge (nach Punkte-Ergiebigkeit)

1. **Motivationstheorien** (Maslow, Herzberg, X/Y, Vroom) — Dauerbrenner, als Anwendungsfall prüfbar
2. **Personalbedarfsplanung mit Rechnung** — sichere Punkte, Schema lernen
3. **Hofstede-Dimensionen + High/Low-Context** — Kern des IKM-Teils
4. **Führungsstile/-theorien** — Entwicklungslinie erzählen können
5. **Personalauswahl** (Anforderungsprofil, Interviewarten, Assessment Center, Gütekriterien)
6. **Personalentwicklung + Beurteilung** (into/near/on/off the job; Beurteilungsfehler!)
7. **Kulturschock, Stereotype, Diversity** — kleinere Punktebringer

## 2. Typische Aufgabentypen + Denkschritte

### Typ A: Theorie auf Fall anwenden ("Analysieren Sie die Situation mit Herzberg")
**Denkschritte (das 4-Schritt-Schema für JEDE Theorieanwendung):**
1. **Theorie in 2–3 Sätzen korrekt wiedergeben** (Begriffe: bei Herzberg Hygienefaktoren vs. Motivatoren)
2. **Fallmerkmale den Theoriebausteinen zuordnen** — jede Information aus dem Text einsortieren ("niedriger Lohn, Schichtchaos" → Hygienefaktoren defizitär; "keine Verantwortung, keine Anerkennung" → Motivatoren fehlen)
3. **Diagnose formulieren:** Was erklärt die Theorie hier? (Unzufriedenheit beseitigen ≠ Motivation erzeugen)
4. **Maßnahmen ableiten, getrennt nach Theoriebausteinen** + 1 Satz Kritik/Grenzen der Theorie
**Häufiger Fehler:** Theorie-Referat ohne Fallbezug ODER Maßnahmenliste ohne Theorie. Die Punkte stecken in der ZUORDNUNG.

### Typ B: Personalbedarf berechnen
**Denkschritte:**
1. Schema aufschreiben (auswendig): **Bruttopersonalbedarf** (Einsatz + Reserve) **− aktueller Personalbestand − sichere Zugänge + sichere Abgänge = Nettopersonalbedarf**
2. Jede Zahl der Angabe einer Zeile zuordnen; Abgänge = Renten, Kündigungen, Elternzeit; Zugänge = Rückkehrer, zugesagte Einstellungen
3. Vorzeichenlogik laut prüfen: Abgänge ERHÖHEN den Bedarf (+), Zugänge senken ihn (−)
4. Ergebnis interpretieren: > 0 Beschaffungsbedarf, < 0 Freisetzungsbedarf (dann Instrumente nennen: natürliche Fluktuation, Arbeitszeitverkürzung … vor Kündigung)
**Häufiger Fehler:** Vorzeichen von Zu-/Abgängen vertauscht. Immer mit dem Merksatz prüfen: "Wer geht, muss ersetzt werden."

### Typ C: Kulturvergleich mit Hofstede
**Denkschritte:**
1. Relevante Dimensionen wählen (nur die, die der Fall hergibt — meist 2–3, z. B. Machtdistanz, Unsicherheitsvermeidung, Individualismus)
2. Beide Kulturen auf den Dimensionen verorten (hoch/niedrig reicht, Punktwerte unnötig)
3. Konfliktpotenzial aus der DIFFERENZ ableiten ("hohe vs. niedrige Machtdistanz → Erwartung an Führungsstil kollidiert: Anweisung erwartet vs. Mitsprache erwartet")
4. Maßnahmen: Bewusstmachung/Training, explizite Team-Regeln, angepasster Führungsstil
5. **Pflicht-Schlusssatz gegen Stereotypen-Falle:** Dimensionen beschreiben Länder-Mittelwerte, nicht Individuen — im Einzelfall Person vor Herkunft.
**Häufiger Fehler:** Hofstede als Charakterbeschreibung einzelner Personen verwenden — gibt Punktabzug.

### Typ D: Auswahlverfahren beurteilen
**Denkschritte:** Gütekriterien als Prüfraster: **Objektivität → Reliabilität → Validität** (+ Ökonomie, Akzeptanz). Verfahren (unstrukturiertes vs. strukturiertes Interview, AC, Arbeitsprobe, Testverfahren) gegen das Raster laufen lassen. Kernwissen: unstrukturierte Interviews haben niedrige prognostische Validität; Struktur + Arbeitsprobe erhöhen sie.

## 3. Häufige Fehlerquellen (vor Abgabe prüfen)

- [ ] Herzberg: Hygienefaktoren beseitigen Unzufriedenheit, erzeugen aber KEINE Zufriedenheit — richtig herum argumentiert?
- [ ] Maslow: als Stufenmodell mit Kritik (kaum empirisch belegt, kulturgebunden) dargestellt?
- [ ] Personalbedarf: Vorzeichen Zugänge/Abgänge?
- [ ] Hofstede: Stereotypen-Disclaimer gesetzt? Dimension korrekt benannt (Machtdistanz ≠ Hierarchieliebe des Einzelnen)?
- [ ] Beurteilungsfehler benennbar (Halo-Effekt, Milde-/Strenge-Tendenz, Recency-Effekt, Ähnlichkeitseffekt)?
- [ ] Fallbezug in JEDER Antwort (mind. 1 Zitat/Detail aus dem Aufgabentext pro Absatz)?
- [ ] Standard-Endkontrolle [[03_Resources/Lernmethoden_Referenz|§6]]
