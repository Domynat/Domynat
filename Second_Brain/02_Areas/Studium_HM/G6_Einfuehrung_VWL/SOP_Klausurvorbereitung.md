# G6 VWL — SOP Klausurvorbereitung

> Grafik-/Modellfach: Jede Lerneinheit endet mit einer HANDGEZEICHNETEN Grafik aus dem Kopf. Lernmethodik: [[03_Resources/Lernmethoden_Referenz|Lernmethoden_Referenz]].

## 1. Themenreihenfolge

1. **Angebot/Nachfrage/Gleichgewicht** — Fundament, ohne das nichts geht
2. **Elastizitäten** (Preis-, Einkommens-, Kreuzpreis-) — Rechnen + Interpretieren
3. **Staatseingriffe** (Höchst-/Mindestpreis, Steuer) + Renten/Wohlfahrt
4. **Marktversagen** (externe Effekte, öffentliche Güter, Info-Asymmetrie)
5. **BIP & Inflation** — Rechenaufgaben (nominal/real, Deflator, VPI)
6. **Geld-/Fiskalpolitik, Konjunktur, magisches Viereck** — Wirkungsketten

## 2. Typische Aufgabentypen + Denkschritte

### Typ A: Marktdiagramm — Schock einordnen
**Denkschritte (IMMER diese 4 Fragen):**
1. **Welche Kurve?** Betrifft der Schock Käufer (→ Nachfrage) oder Verkäufer (→ Angebot)? (Einkommen, Präferenzen, Preis Substitut/Komplement → N; Inputkosten, Technologie, Anbieterzahl → A)
2. **Welche Richtung?** Mehr gewünschte Menge bei jedem Preis → rechts; weniger → links.
3. **Preisänderung selbst = Bewegung AUF der Kurve, nie Verschiebung!** (häufigster Klausurfehler)
4. **Neues Gleichgewicht ablesen:** p und x im Vergleich zu vorher; bei Doppelschocks: eine Größe eindeutig, die andere "ambivalent, abhängig von Stärke".
Dann: Grafik mit beschrifteten Achsen (p, x), Kurven (N₀→N₁), Gleichgewichten (E₀, E₁).

### Typ B: Gleichgewicht rechnen (lineare Funktionen)
**Denkschritte:** N: x = a − b·p; A: x = c + d·p → gleichsetzen, p* auflösen, x* durch Einsetzen, **Probe in der anderen Gleichung**. Konsumentenrente = Dreieck zwischen Nachfragekurve und p* (Fläche = ½ × Basis × Höhe); Produzentenrente spiegelbildlich. ([[03_Resources/Mathe_Grundlagen_Klausuren|Mathe §4]])

### Typ C: Elastizität berechnen + interpretieren
**Denkschritte:**
1. Formel: ε = %Δ Menge / %Δ Preis (Punkt- oder Bogenelastizität je Angabe — Vorgabe im Skript prüfen)
2. Betrag interpretieren: |ε| > 1 elastisch, < 1 unelastisch, = 1 proportional
3. **Umsatzregel anwenden:** unelastisch → Preiserhöhung steigert Umsatz; elastisch → Preissenkung steigert Umsatz
4. Hospitality-Transfer als Bonus: Geschäftsreisende unelastisch / Urlauber elastisch → Preisdifferenzierung ([[02_Areas/Studium_HM/G9_Grundlagen_Hospitality_Management/Konzepte|G9 Revenue Mgmt]])
**Häufiger Fehler:** Vorzeichen-Panik (Preiselastizität der Nachfrage ist normal negativ — Interpretation über |ε|); Prozentänderungen von der falschen Basis.

### Typ D: Staatseingriff bewerten
**Denkschritte:** 1) Eingriff einzeichnen (Höchstpreis UNTER p* wirkt, Mindestpreis ÜBER p*) → 2) Mengeneffekt: kurze Marktseite bestimmt Menge → Nachfrageüberschuss (Höchstpreis) bzw. Angebotsüberschuss (Mindestpreis) → 3) Folgeeffekte: Schwarzmarkt, Qualitätsverfall, Rationierung / Überproduktion → 4) Wohlfahrtsverlust-Dreieck benennen. Bei Steuern: Steuerlast-Verteilung hängt von Elastizitäten ab — die UNelastischere Seite trägt mehr.

### Typ E: BIP/Inflation rechnen
**Denkschritte:** Nominales BIP = Σ p_t × x_t; reales BIP = Σ p_Basisjahr × x_t; **Deflator = nominal/real × 100**; Wachstum real = (BIP_real,t / BIP_real,t−1 − 1). Abgrenzen: BIP (Inlandskonzept) vs. BNE (Inländerkonzept); nicht enthalten: Schwarzarbeit, Hausarbeit, Gebrauchtwaren, reine Finanztransaktionen.

### Typ F: Wirkungskette Geldpolitik
**Muster (expansiv):** EZB senkt Leitzins → Refinanzierung der Banken billiger → Kreditzinsen sinken → Investitionen/Konsum steigen → gesamtwirtschaftliche Nachfrage ↑ → Produktion/Beschäftigung ↑, mittelfristig Preisdruck ↑. Restriktiv: alle Pfeile umdrehen. Immer 4–6 Kettenglieder ausschreiben — Stichwort "Leitzins runter = gut" gibt keine Punkte.

## 3. Häufige Fehlerquellen (vor Abgabe prüfen)

- [ ] Bewegung auf vs. Verschiebung der Kurve sauber getrennt?
- [ ] Achsen/Kurven/Gleichgewichte beschriftet?
- [ ] Elastizität: richtige Basis, Interpretation mit |ε| + Umsatzregel?
- [ ] Höchstpreis unter p* / Mindestpreis über p* (sonst wirkungslos)?
- [ ] Kurze Marktseite bestimmt gehandelte Menge?
- [ ] Real vs. nominal: Basisjahrpreise verwendet?
- [ ] Wirkungsketten vollständig (min. 4 Glieder)?
- [ ] Standard-Endkontrolle [[03_Resources/Lernmethoden_Referenz|§6]]
