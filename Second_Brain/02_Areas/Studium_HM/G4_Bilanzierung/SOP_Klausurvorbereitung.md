# G4 Bilanzierung — SOP Klausurvorbereitung

> **Rechenfach-Regel:** 20 % Theorie, 80 % Aufgaben. Primärer Übungspool: [[Bilanzierung_Klausurtraining]] (dort drillen), hier stehen Strategie, Denkschritte und Fehlerlisten. Rechen-Basics: [[03_Resources/Mathe_Grundlagen_Klausuren|Mathe_Grundlagen_Klausuren]].

## 1. Themenreihenfolge (aufeinander aufbauend — Reihenfolge NICHT tauschen)

1. **Bilanzlogik & Kontenlehre:** Aktiv-/Passivkonten, Mehrung/Minderung, Bilanzgleichung — ohne das wird alles Weitere Raten
2. **Laufende Buchungen mit USt:** Einkauf, Verkauf, Skonto, Retouren — Masse der Klausurpunkte
3. **Abschreibungen:** linear, ggf. degressiv/leistungsbezogen; GWG-Regeln; außerplanmäßig
4. **Abschlussbuchungen:** RAP, Rückstellungen, Forderungsbewertung (EWB/PWB), Bestandsveränderungen
5. **Bewertung:** AK/HK-Bestandteile (§ 255), Niederstwertprinzip (streng/gemildert), Bewertungsprinzipien § 252
6. **Theorieteil:** GoB, Jahresabschluss-Bestandteile, Größenklassen, Inventur/Inventar — Lernstoff, zuletzt

## 2. Typische Aufgabentypen + Denkschritte

### Typ A: Buchungssätze bilden
**Denkschritte (mechanisch anwenden, IMMER in dieser Reihenfolge):**
1. **Welche zwei (oder mehr) Konten sind betroffen?** (Sachverhalt in Konten übersetzen)
2. **Kontenart je Konto:** Aktiv / Passiv / Aufwand / Ertrag?
3. **Mehrung oder Minderung je Konto?**
4. **Buchungsregel anwenden:** Aktiv: Mehrung im Soll. Passiv: Mehrung im Haben. Aufwand: im Soll. Ertrag: im Haben.
5. **USt prüfen:** Eingangsrechnung → Vorsteuer (Aktivkonto, Soll); Ausgangsrechnung → Umsatzsteuer (Passivkonto, Haben). Brutto/Netto trennen ([[03_Resources/Mathe_Grundlagen_Klausuren|§1: vom Brutto wird geteilt]]).
6. **Formal aufschreiben:** `Soll-Konto Betrag an Haben-Konto Betrag` — Summen Soll = Summen Haben prüfen.

### Typ B: Abschreibungsplan erstellen
**Denkschritte:**
1. **AK/HK bestimmen (§ 255 HGB):** Kaufpreis − Rabatte/Skonti + direkt zurechenbare Nebenkosten (Transport, Montage, Zoll). NICHT: Vorsteuer (bei Abzugsberechtigung), laufende Betriebskosten.
2. Nutzungsdauer & Methode aus Angabe (i. d. R. linear: AK / ND pro Jahr).
3. **Zeitanteiligkeit (pro rata temporis):** Anschaffung im Jahr → monatsgenau ab Anschaffungsmonat (Kauf 10.04. → 9/12 im ersten Jahr).
4. Tabelle: Jahr | AfA | Buchwert 31.12. — bis Restbuchwert 0 € (oder Erinnerungswert 1 €).
5. Buchungssatz: `Abschreibungen an Anlagekonto`.

### Typ C: Rechnungsabgrenzung (RAP)
**Denkschritte — zwei Fragen, dann steht der Posten:**
1. **Wer hat gezahlt?** Wir zahlen VORAUS → **aktiver RAP** ("Vorleistung = Vermögenswert"). Wir erhalten VORAUS → **passiver RAP** ("Verpflichtung, noch zu leisten").
2. **Welcher Anteil gehört ins nächste Jahr?** Nur dieser Anteil wird abgegrenzt (zeitanteilig rechnen).
3. Merksatz Konten: **ARAP = Aufwand später** (gezahlter Aufwand, der wirtschaftlich ins Folgejahr gehört); **PRAP = Ertrag später**.
4. Sonderfall antizipativ (sonstige Forderungen/Verbindlichkeiten): Leistung dieses Jahr, Zahlung nächstes Jahr.

### Typ D: Bewertungsaufgabe (Niederstwertprinzip)
**Denkschritte:**
1. Vermögensart bestimmen: **Umlaufvermögen → strenges NWP** (JEDE Wertminderung abschreiben); **Anlagevermögen → gemildertes NWP** (nur bei voraussichtlich DAUERHAFTER Minderung).
2. Vergleichswerte am Stichtag: Buchwert vs. beizulegender Wert/Börsen-/Marktpreis.
3. Niedrigeren Wert ansetzen (UV) bzw. Dauerhaftigkeit diskutieren (AV).
4. Wertaufholung: spätere Werterholung → Zuschreibung PFLICHT (max. bis fortgeführte AK/HK).
5. Prinzipien als Begründung zitieren: Vorsichts-, Imparitäts-, Realisationsprinzip (§ 252 HGB).

### Typ E: Forderungsbewertung
**Denkschritte:** Einwandfreie (nominal) / zweifelhafte (EWB in Höhe des Ausfallrisikos, auf NETTO-Forderung!) / uneinbringliche (voll abschreiben, USt korrigieren) Forderungen trennen → PWB auf den Rest-Nettobestand → Buchungssätze.

## 3. Häufige Fehlerquellen (vor Abgabe explizit prüfen)

- [ ] USt/Vorsteuer vergessen oder auf Bruttobasis gerechnet?
- [ ] Skonto: mindert AK bzw. Verbindlichkeit — Vorsteuer-/USt-Korrektur mitgebucht?
- [ ] AfA zeitanteilig (Kaufmonat!) statt volles Jahr?
- [ ] AK-Nebenkosten aufgenommen, laufende Kosten draußen gelassen?
- [ ] RAP-Richtung vertauscht (aktiv = ich habe vorausgezahlt)?
- [ ] EWB auf Nettoforderung (ohne USt) gebildet?
- [ ] Strenges (UV) vs. gemildertes (AV) NWP korrekt zugeordnet?
- [ ] Soll-Summe = Haben-Summe bei jedem Buchungssatz?
- [ ] Rückstellung (dem Grunde/der Höhe nach ungewiss) vs. Verbindlichkeit (beides gewiss) vs. Rücklage (Eigenkapital!) unterschieden?
- [ ] Standard-Endkontrolle [[03_Resources/Lernmethoden_Referenz|§6]]
