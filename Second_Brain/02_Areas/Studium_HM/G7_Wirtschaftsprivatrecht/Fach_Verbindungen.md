# G7 Wirtschaftsprivatrecht — Verbindungen zu anderen Modulen

| G7-Konzept | Taucht wieder auf in | Wie |
|---|---|---|
| Kaufmannsbegriff, Rechtsformen (HGB) | [[02_Areas/Studium_HM/G1_Einfuehrung_ABWL/Konzepte\|G1]], [[02_Areas/Studium_HM/G4_Bilanzierung/Konzepte\|G4]] | G1 wählt die Rechtsform betriebswirtschaftlich, G7 liefert Haftung/Vertretung, G4 knüpft die Buchführungspflicht (§ 238 HGB) an die Kaufmannseigenschaft |
| Vertragstypen (Miete/Pacht/Dienst/Werk) | [[02_Areas/Studium_HM/G3_Grundlagen_Hospitality/Konzepte\|G3]] | Betreibermodelle sind juristisch Pacht- bzw. Geschäftsbesorgungs-/Managementverträge — G7 erklärt, warum die Risikoverteilung so ist |
| Arbeitsvertrag = Dienstvertrag | [[02_Areas/Studium_HM/G2_Personal_Interkulturelles_Management/_Uebersicht\|G2]] | Personalinstrumente stehen auf schuldrechtlichem Fundament |
| Pauschalreiserecht §§ 651a ff. | G3 (Veranstalter vs. Mittler) | Juristische Trennlinie erklärt die ökonomische Rollenverteilung |
| AGB-Kontrolle | G9 (Storno-/Ratenpolitik), [[02_Areas/Studium_HM/G10_Digitale_Technologien_Distribution/Konzepte\|G10]] (OTA-Buchungsbedingungen) | Revenue-Management-Fences müssen AGB-fest formuliert sein |
| Informationsasymmetrie & Verbraucherschutz | [[02_Areas/Studium_HM/G6_Einfuehrung_VWL/Konzepte\|G6]] | Zwingendes Verbraucherrecht als staatliche Antwort auf Marktversagen |
| Verkehrssicherungspflicht, Gastwirtshaftung | G9 (Risikomanagement, Versicherungen) | Operative Standards (Wet-Floor-Schilder, Safe-Prozesse) haben juristische Wurzeln |
| Prinzipal-Agent → Vertretungsrecht | [[00_System/Konzept_Bibliothek\|Konzept_Bibliothek]] | Vollmachtsgrenzen und Prokura-Standardisierung sind institutionalisierte Agency-Kontrolle |
| Gutachtenstil als Denkmethode | [[02_Areas/Code_Standards/Persoenliche_Code_Konventionen/SOP_Code_Review\|SOP_Code_Review]], Investing | Voraussetzungen definieren → Fakten subsumieren → Ergebnis: dieselbe Disziplin wie eine Checklisten-Prüfung |

**Lern-Hebel:** Der Gutachtenstil ist ein universelles Prüfschema — wer ihn kann, strukturiert auch BWL-Fallaufgaben (G1/G2/G3) sauberer: Kriterium definieren → Fall zuordnen → Zwischenfazit.
