# G5 KLR & Finanzierung — Kernkonzepte

## Begriffsabgrenzung (Fundament)

**Vier Ebenen (mit Gegenstücken):** Auszahlung/Einzahlung (Zahlungsmittel) → Ausgabe/Einnahme (Geldvermögen) → Aufwand/Ertrag (GuV, externes RW → [[02_Areas/Studium_HM/G4_Bilanzierung/Konzepte|G4]]) → **Kosten/Leistung** (betriebszweckbezogener, bewerteter Güterverzehr — internes RW).

**Überleitung Aufwand → Kosten:** Aufwand − neutraler Aufwand (betriebsfremd, periodenfremd, außerordentlich) + kalkulatorische Kosten = Kosten. **Anderskosten** (aufwandsverschieden: kalk. Abschreibung auf Wiederbeschaffungswert, kalk. Wagnisse), **Zusatzkosten** (aufwandslos: kalk. Unternehmerlohn, kalk. Eigenkapitalzinsen, kalk. Miete) — ökonomische Begründung: [[00_System/Konzept_Bibliothek|Opportunitätskosten]].

**Kostenbegriffe:** fix/variabel (Reaktion auf Beschäftigung), Einzel-/Gemeinkosten (Zurechenbarkeit auf Träger), primär/sekundär. Achtung: fix≠Gemeinkosten (Akkordlohn = variabel + Einzel; Gebäudemiete = fix + Gemein; Hilfsstoffe oft variabel + Gemein).

## Der KLR-Dreischritt

**1. Kostenartenrechnung** — WELCHE Kosten? (Material, Personal, AfA, kalkulatorische …)

**2. Kostenstellenrechnung (BAB)** — WO entstanden? Gemeinkostenverteilung über Schlüssel auf Material-/Fertigungs-/Verwaltungs-/Vertriebsstellen; Ergebnis: **Zuschlagssätze** (MGK auf MEK; FGK auf Fertigungslöhne; VwGK+VtGK auf Herstellkosten des Umsatzes). Innerbetriebliche Leistungsverrechnung (Anbau-/Stufenleiter) einordnen können.

**3. Kostenträgerrechnung** — WOFÜR? **Zuschlagskalkulation** (Schema in [[02_Areas/Studium_HM/G5_Internes_Rechnungswesen_Finanzierung/SOP_Klausurvorbereitung|SOP §2C]]); **Divisionskalkulation** (Einprodukt: Kosten/Menge); **Äquivalenzziffern** (ähnliche Produkte). Hotellerie-Anwendung: Kalkulation von Menüpreisen, Bankett-Angeboten, Zimmerraten-Untergrenzen.

## Teilkostenrechnung (Entscheidungsrechnung)

**Kritik Vollkosten:** Fixkosten werden proportionalisiert → bei Beschäftigungsschwankungen und kurzfristigen Entscheidungen systematisch falsch ("Fixkostenfalle": Produkt wirkt defizitär, deckt aber Fixkosten mit).

**Deckungsbeitrag:** db = p − kv (Stück); DB = db × x; Betriebsergebnis = DB − Kf. **Mehrstufige Fixkostendeckung** (Produkt-/Bereichs-/Unternehmensfixkosten) zeigt, WO Fixkosten verursacht werden.

**Entscheidungsregeln (Klausur-Gold):** Zusatzauftrag: p > kv bei freier Kapazität; Preisuntergrenzen: kurzfristig kv, langfristig Vollkosten; Engpass: **db je Engpasseinheit** maximieren; Eliminierung: nur bei db < 0; Eigenfertigung/Fremdbezug: relevante Kosten vergleichen (nur entscheidungsabhängige!).

**Break-even:** x_BE = Kf/(p−kv); grafisch + rechnerisch; Aussage: ab dieser Menge decken DBs die Fixkosten. Hotellerie: Mindestauslastung, ab der ein Öffnungstag/Outlet sich trägt → [[02_Areas/Studium_HM/G9_Grundlagen_Hospitality_Management/Konzepte|G9 CPOR]].

## Finanzierung

**Systematik (2×2 lernen):**

| | Außenfinanzierung | Innenfinanzierung |
|---|---|---|
| **Eigenkapital** | Einlagen/Beteiligung (auch Börsengang) | Selbstfinanzierung (Gewinnthesaurierung) |
| **Fremdkapital** | Kredite, Anleihen, Lieferantenkredit | Finanzierung aus Rückstellungen |
| (Sonderformen) | Leasing, Factoring, Mezzanine | Finanzierung aus AfA-Gegenwerten (Kapazitätserweiterungseffekt) |

**Kreditformen:** Kontokorrent (teuer, flexibel), Darlehen (Tilgungsarten: endfällig/Raten-/Annuität), Lieferantenkredit (Skonto-Verzicht ist TEUER: Effektivzins ≈ Skontosatz/(Zahlungsziel−Skontofrist)×360 — rechnen können!), Avalkredit.

**Leasing vs. Kauf:** Liquiditätsschonung, Bilanzneutralität (operating), Flexibilität ↔ Gesamtkosten meist höher, kein Eigentum. Hotellerie: verbreitet bei Technik/Fuhrpark.

**Leverage-Effekt:** r_EK = r_GK + (r_GK − i) · FK/EK. Chance und Risiko symmetrisch; Grenze: steigendes FK → steigender Zins i (Bonität) → Hebel frisst sich selbst auf. → Investing-Parallele: [[02_Areas/Finanzen_Investing/Buffett_Value_Investing_SOP/Kennzahlen_Referenz|Verschuldungsgrad-Schwellen]].

**Finanzierungsregeln:** Goldene Finanzierungsregel (Fristenkongruenz: langfristiges Vermögen langfristig finanzieren); goldene Bilanzregel (AV ≤ EK (+ langfr. FK)); **Liquiditätsgrade:** L1 = Zahlungsmittel/kurzfr. FK; L2 = (ZM + kurzfr. Forderungen)/kurzfr. FK (~100 % Ziel); L3 = UV/kurzfr. FK. Kritik: Stichtagsgrößen, manipulierbar → Finanzplan wichtiger.

**Working Capital** = UV − kurzfristiges FK; > 0 heißt: UV trägt sich langfristig finanziert.

## Investitionsrechnung

**Statisch (eine Periode, Durchschnittswerte):** Kostenvergleich (bei gleichen Erlösen), Gewinnvergleich, Rentabilitätsvergleich (Ø-Gewinn/Ø-Kapitaleinsatz; Ø-Kapital = (AK+RW)/2), Amortisation (AK−RW)/Ø-Rückfluss. Schwächen: ignoriert Zeitpunkte der Zahlungen, Zinseszins.

**Dynamisch (Zahlungsreihen, Abzinsung → [[03_Resources/Mathe_Grundlagen_Klausuren|Mathe §2]]):**
- **Kapitalwert C0** = Σ (Et−At)/(1+i)^t − I0 (+ RW abgezinst). C0 > 0 → vorteilhaft. DAS Kernverfahren — identische Logik wie DCF im Investing ([[02_Areas/Finanzen_Investing/Buffett_Value_Investing_SOP/SOP_Aktienanalyse|SOP_Aktienanalyse]] Schritt 6!).
- **Interner Zinsfuß:** i mit C0=0; Vergleich mit Kalkulationszins; Schwäche: Wiederanlageprämisse, Mehrfachlösungen.
- **Annuitätenmethode:** C0 in gleiche Jahresraten übersetzt (Wiedergewinnungsfaktor).

**Kalkulationszinssatz:** Opportunitätskosten des Kapitals (alternative Anlage + Risikozuschlag) — konzeptionell wichtig, Wert ist in Klausuren gegeben.
