# G1 ABWL — Verbindungen zu anderen Modulen

> G1 ist die Landkarte — fast jedes Konzept kehrt vertieft wieder. Wer G1 kann, lernt die anderen Module schneller; wer ein anderes Modul lernt, sollte den G1-Anker kennen.

| G1-Konzept | Taucht wieder auf in | Wie |
|---|---|---|
| Rentabilität (EK/GK/Umsatz) | [[02_Areas/Studium_HM/G4_Bilanzierung/_Uebersicht\|G4]], [[02_Areas/Studium_HM/G5_Internes_Rechnungswesen_Finanzierung/_Uebersicht\|G5]], [[02_Areas/Finanzen_Investing/Buffett_Value_Investing_SOP/Kennzahlen_Referenz\|Investing]] | G4 liefert die Gewinngröße (GuV), G5 den Leverage-Effekt, Investing nennt es ROE/ROA |
| Rechtsformen | [[02_Areas/Studium_HM/G7_Wirtschaftsprivatrecht/_Uebersicht\|G7]] | G7 liefert die juristische Tiefe: Kaufmannseigenschaft, Vertretungsmacht, Haftungsnormen (HGB) |
| Wirtschaftlichkeitsprinzip, Knappheit | [[02_Areas/Studium_HM/G6_Einfuehrung_VWL/_Uebersicht\|G6]] | VWL formalisiert Knappheit (Opportunitätskosten, PMK) auf Volkswirtschaftsebene |
| Marketing-Mix (7P), STP | [[02_Areas/Studium_HM/G9_Grundlagen_Hospitality_Management/_Uebersicht\|G9]], [[02_Areas/Studium_HM/G10_Digitale_Technologien_Distribution/_Uebersicht\|G10]] | G9 wendet den Mix auf Hotellerie an (Preis-/Ratenpolitik), G10 vertieft "Place" als digitale Distribution (OTA, GDS, Direktkanal) |
| Dienstleistungsbesonderheiten (angerissen) | [[02_Areas/Studium_HM/G3_Grundlagen_Hospitality/_Uebersicht\|G3]] | G3 macht daraus das Kern-Framework (Immaterialität, uno-actu, Nichtlagerbarkeit) |
| Personalfunktion | [[02_Areas/Studium_HM/G2_Personal_Interkulturelles_Management/_Uebersicht\|G2]] | Aus einer Funktionsfolie wird ein ganzes Modul (Rekrutierung bis Führung) |
| ABC-Analyse / Pareto | [[00_System/Konzept_Bibliothek\|Konzept_Bibliothek]], G5 (Materialkosten), G9 (Menü-/Gästeanalyse) | Gleiche Rechentechnik, andere Objekte |
| Zielkonflikt Rentabilität↔Liquidität↔Sicherheit | G5 (Finanzierungsregeln), Investing ([[02_Areas/Finanzen_Investing/Buffett_Value_Investing_SOP/Philosophie\|Philosophie]]) | Magisches Dreieck = Vorläufer der Risiko/Rendite-Abwägung |
| BCG/SWOT/Lebenszyklus | G9 (Strategie für Hotelketten), G10 (Technologie-Adoption) | Werkzeuge wandern mit, Objekte ändern sich |

**Lern-Hebel:** Beim Lernen eines anderen Moduls zuerst fragen: "Wie hieß das in G1?" — vorhandenes Vorwissen aktivieren spart Neuaufbau (Prinzip: Anker vor Detail).
