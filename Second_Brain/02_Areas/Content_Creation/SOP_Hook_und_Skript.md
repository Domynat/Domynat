# SOP Hook & Skript

> **Regel Nr. 1:** Der Hook (Sekunde 0–3) entscheidet über 60–80 % der Performance. Erst Hook wählen und ausformulieren, DANN den Rest schreiben. Ton/No-Gos: [[02_Areas/Content_Creation/Nische_Positionierung|Nische_Positionierung]].

## 1. Hook-Formeln (Formel → warum sie wirkt → Beispiel aus meiner Nische)

1. **Ergebnis zuerst:** Zeige das Endresultat vor jeder Erklärung. *Wirkt, weil Beweis Neugier auf den Weg erzeugt.* — „Dieses Video hat mein KI-Agent gerade selbst gepostet. So hab ich das gebaut."
2. **Negativ-Erfahrung (Anti-Guru):** Fehler/Fail zuerst. *Ehrlichkeit ist in der KI-Nische selten → Pattern-Break.* — „Mein KI-Agent hat 3 Posts komplett verkackt. Das war der Grund."
3. **Zahlen-Behauptung:** Konkrete, leicht unglaubliche Zahl. *Spezifisch schlägt vage.* — „Ich habe 10 Uni-Module in 69 Dateien dokumentiert — und jetzt löst die KI meine Übungsklausuren."
4. **Verbotener-Blick / Insider:** „Was keiner zeigt". *Exklusivitäts-Trigger.* — „So sieht das Second Brain von innen aus, das mein ganzes Studium steuert."
5. **Du-Problem-Spiegel:** Avatar-Schmerz wörtlich aussprechen. *Selbsterkennung stoppt den Daumen.* — „Du hast Notion eingerichtet und nach 2 Wochen aufgegeben? Das hier ist der Grund."
6. **Vorher/Nachher-Sprung:** Kontrast in einem Satz. *Transformation = Kernversprechen.* — „Vor 30 Tagen: Chaos. Heute plant mein Agent meinen Tag, bevor ich aufwache."
7. **Countdown/Challenge:** Laufendes Experiment mit offenem Ausgang. *Serien-Bindung, Wiederkommen.* — „Tag 12 von 90: Kann ein KI-Agent einen Studenten profitabel machen?"
8. **Kontroverse These:** Begründbarer Widerspruch zur Mehrheitsmeinung. *Kommentar-Magnet (Algorithmus-Signal).* — „ChatGPT-Prompts sind wertlos. Systeme sind alles."
9. **Stiller Beweis (Visual Hook):** 3 Sek Screen-Action ohne Erklärung, Text-Overlay stellt die Frage. *Für stumme Scroller.* — [Screen: Agent legt Posts an] Overlay: „Er arbeitet. Ich schlafe."

**Wahlregel:** Säule 1/2 → Formeln 1, 3, 4, 9 · Säule 3 → 2, 6, 7 · Säule 4 → 2, 8. Pro Woche mind. 2 verschiedene Formeln (Messbarkeit). Schwach getestete Formeln (Retention < 60 % nach 3 Sek, siehe [[02_Areas/Content_Creation/SOP_Content_Engine|Engine §6]]) hier markieren: *(bisher schwach: —)*

## 2. Skript-Vorlagen je Format

### Short/Reel/TikTok (20–45 Sek) — Standardformat
```
[0–3 s]  HOOK (Formel aus §1, wörtlich ausformuliert) + Text-Overlay mit Kernaussage
[3–8 s]  KONTEXT in 1 Satz: Was sehe ich hier / warum relevant für DICH
[8–35 s] KERN: 3 Beats (je Beat = 1 Aussage + 1 sichtbarer Beweis im Screen).
         Beat-Wechsel = Schnitt + neues Overlay. NIE 2 Aussagen ohne Bildwechsel.
[35–42 s] PAYOFF: Ergebnis/Learning in 1 Satz („Merk dir: …")
[letzte 3 s] CTA (aus §4) — gesprochen UND als Overlay
```

### YouTube-Long (5–10 Min) — 1×/Woche max., Anker-Format
```
[0–20 s]   Cold Open: Ergebnis zeigen + Versprechen („Am Ende hast du X")
[20–60 s]  Roadmap: die 3 Schritte nennen (Kapitelmarken!)
[Hauptteil] 3 Kapitel à 1,5–3 Min: je Schritt = Zeigen (Screen) → Erklären (1–2 Sätze) → Stolperfalle
[Schluss]  Ergebnis-Recap + CTA Lead-Magnet + Anschlussvideo nennen (Session-Time!)
```

### Karussell/Text-Post (IG, Bonus-Format)
7 Slides: Slide 1 = Hook-Satz groß · Slides 2–6 = je 1 Schritt/Punkt mit Screenshot · Slide 7 = CTA. Aus jedem Short-Skript ableitbar (Beats = Slides).

## 3. Retention-Techniken (in jedes Skript einbauen)

- **Open Loop:** Im Hook etwas versprechen, das erst im Payoff eingelöst wird („…und einer der 3 Schritte kostet 0 €" → welcher, kommt am Ende)
- **Pattern-Interrupts:** alle 5–8 Sek sichtbare Änderung (Zoom, Overlay, Szenenwechsel)
- **Konkretion:** jede abstrakte Aussage sofort mit Screen-Beweis („der Agent liest meine SOP" → SOP-Datei ist im Bild)
- **Kein Intro-Geschwafel:** Wörter wie „Hey Leute, heute…" sind verboten — erster Satz IST der Hook
- **Re-Hook bei Longs:** alle 60–90 Sek Mini-Cliffhanger („gleich zeig ich dir den Fehler, der mich 2 Wochen gekostet hat")

## 4. CTA-Bibliothek (Monetarisierungs-Anschluss, [[02_Areas/Content_Creation/Monetarisierung_Referenz|Referenz]])

| Ziel | CTA-Text (Beispiel) | Einsatz |
|---|---|---|
| **Lead-Magnet** (Priorität!) | „Das komplette Template gibt's kostenlos — Link in der Bio, schick dir's per Mail." | jedes 2. Video |
| Folgen/Serie | „Tag 13 kommt morgen — folg mir, wenn du das Ende sehen willst." | Serien-Content |
| Kommentar-Trigger | „Team Notion oder Team Obsidian? Kommentare." | Säule 4, Kontroversen |
| Produkt (ab Launch) | „Das fertige Vault-Template findest du im Link — kostet weniger als eine Pizza." | max. 1×/Woche, mit Werbekennzeichnung ([[02_Areas/Content_Creation/Compliance_Checkliste|Compliance]]) |
| Cross-Plattform | „Das 10-Minuten-Deep-Dive dazu ist auf YouTube." | Shorts → Long |

**Regel:** genau EIN CTA pro Video. Zwei CTAs = null CTAs.

## 5. Beispiel-Skripte (Few-Shot — Format exakt so übernehmen)

### Beispiel A: Short, Säule 1, Hook-Formel 1 („Agent-Log #1")
```
TITEL (intern): Agent postet selbst — Setup in 3 Schritten
HOOK [0–3 s], on camera: „Dieses Video wurde von meinem KI-Agenten hochgeladen.
  Nicht von mir." | Overlay: „Mein Agent postet für mich 🤖"
KONTEXT [3–8 s], Screen: „Das ist Hermes — mein Agent. Er plant, betitelt und
  postet meine Videos. Ich zeig dir die 3 Bausteine."
BEAT 1 [8–16 s], Screen Notion: „Baustein 1: ein Redaktionsplan in Notion.
  Jede Idee ist eine Karte mit Status." | Overlay: „1. Redaktionsplan"
BEAT 2 [16–25 s], Screen Vault: „Baustein 2: eine SOP. Hier steht Schritt für
  Schritt, wie ein Post auszusehen hat — der Agent liest das wie ein Rezept."
  | Overlay: „2. SOP = Rezept"
BEAT 3 [25–33 s], Screen Post Proxy: „Baustein 3: der Poster. Der nimmt das
  fertige Video und plant es ein. Ich geb nur noch das Okay." | Overlay: „3. Auto-Posting"
PAYOFF [33–40 s], on camera: „Merk dir: Der Agent ist nicht schlau. Das SYSTEM
  ist schlau. Er folgt nur meinen Regeln."
CTA [40–43 s]: „Die Vorlage für genau diesen Redaktionsplan gibt's kostenlos —
  Link in der Bio." | Overlay: „Gratis-Template 👉 Bio"
```

### Beispiel B: Short, Säule 3, Hook-Formel 2 („Fail der Woche #4")
```
TITEL (intern): Agent-Fail — falsches Video geplant
HOOK [0–3 s], on camera, ernst: „Mein Agent hätte fast ein unfertiges Video
  gepostet. An 40.000 Leute." | Overlay: „Fast-Katastrophe 😬"
KONTEXT [3–9 s], Screen: „Hier: Status stand auf ‚Bereit', war aber der rohe
  Schnitt. Der Agent kann Status lesen — aber nicht Qualität sehen."
BEAT 1 [9–17 s]: „Fehler: Ich hatte die Freigabe-Regel gestrichen, weil's
  schneller ging. Eine Woche lang gut gegangen." | Overlay: „Regel gelöscht = Risiko"
BEAT 2 [17–26 s], Screen SOP: „Fix: In der SOP steht jetzt ein hartes Gate:
  NICHTS geht live ohne mein Okay. Der Agent plant nur bis ‚wartet auf Freigabe'."
  | Overlay: „Freigabe-Gate 🔒"
PAYOFF [26–34 s], on camera: „Learning: Automatisiere die Arbeit, nie die
  Verantwortung."
CTA [34–37 s]: „Folg mir für den nächsten Fail — der kommt sicher." (Serien-CTA)
```

**Format-Regeln aus den Beispielen (verbindlich):** Timestamps + Sprechtext wörtlich + Overlay-Text wörtlich + Bildquelle je Abschnitt (on camera/Screen X). Ein Skript ohne diese 4 Elemente ist unfertig.
