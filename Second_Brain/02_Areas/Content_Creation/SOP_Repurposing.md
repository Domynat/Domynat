# SOP Repurposing — 1 Kern-Asset → N native Fassungen

> **Grundsatz:** Repurposing heißt NICHT „gleiche Datei überall hochladen" (Wasserzeichen + identische Metadaten werden abgestraft, [[02_Areas/Content_Creation/Plattform_Spielregeln|Plattform_Spielregeln]]). Es heißt: gleiche IDEE, plattform-nativ neu verpackt. Aufwand pro Zusatzfassung: 10–20 Min.

## 1. Ausgangslage bestimmen

**Fall A — Master ist ein Long-Video (YouTube, 5–10 Min):** 2–4 Clip-Kandidaten identifizieren. Kandidaten-Regel: jede Stelle, die (a) einen Beat vollständig enthält (Aussage + Beweis + Mini-Payoff) und (b) OHNE Kontext des Restvideos verständlich ist. Je Kandidat → Schritt 2.

**Fall B — Master ist ein Short-Skript (9:16, 20–45 Sek):** Das Master-Video ist Basis; je Plattform wird Hook-Anfang, Caption, Hashtags und ggf. erste 3 Sekunden neu gebaut → Schritt 2.

## 2. Umbau-Regeln je Plattform (Tabelle — mechanisch anwenden)

| Element | YouTube-Short | Instagram Reel | TikTok |
|---|---|---|---|
| Länge | 20–40 s (max. 60 s als Grenze denken, nicht Ziel) | **15–30 s optimal**, bis 60 s wenn dicht | 25–60 s; **≥ 60 s nur, wenn auf Creator Rewards eingezahlt wird** (dann 60–90 s, [[02_Areas/Content_Creation/Monetarisierung_Referenz|Referenz]]) |
| Format | 9:16, 1080×1920 | 9:16, 1080×1920 (Cover 3:4 wählbar) | 9:16, 1080×1920 |
| Hook-Timing | 0–2 s hart (Feed skippt schnellstens) | 0–3 s; erste Frame muss als Standbild funktionieren (Cover!) | 0–3 s; Sprechtempo hoch, Overlay sofort |
| Untertitel | eingebrannt, groß, Mitte-unten | eingebrannt + saubere Rechtschreibung (Ästhetik zählt auf IG) | eingebrannt; TikTok-Auto-Captions zusätzlich aktivieren |
| Text-Overlay | 1 Kernaussage pro Beat | dito, aber dezenter/cleaner Stil | dito, darf ruppiger/nativer wirken |
| Sound | Voice-over dominiert; Musik leise | trending-nahe Musik dezent unterlegen (lizenzsicher! [[02_Areas/Content_Creation/Compliance_Checkliste\|Compliance]]) | Voice + ggf. TikTok-nativer Sound; Sounds aus TikTok-Bibliothek nur für TikTok |
| Caption | 1 Zeile + 2–3 Keywords (YouTube-Suche!) | Hook-Satz + 3–5 Zeilen Mehrwert + CTA | kurz, 1 Frage/These (Kommentar-Trigger) |
| Hashtags | 2–3 thematisch | 3–5 (Nische + Format, keine Spam-Listen) | 3–5, Mix aus Nische + breit |
| CTA-Anpassung | „Ganzes Video auf dem Kanal" erlaubt | „Link in Bio" (Links nur in Bio!) | „Link in Bio"; Serien-CTA wirkt am stärksten |
| KI-Kennzeichnung | bei realistisch wirkendem KI-Material aktivieren | dito (Meta-Label) | dito (TikTok-Toggle) — Details [[02_Areas/Content_Creation/Compliance_Checkliste\|Compliance]] |

**Verbots-Regel:** TikTok-Export mit Wasserzeichen NIEMALS auf Reels/Shorts hochladen (und umgekehrt) — immer aus dem Schnittprojekt exportieren.

## 3. Ablauf pro Zusatzfassung (10–20 Min, mechanisch)

1. Master-Projekt duplizieren (im Schnitt-Tool)
2. Zeile für Zeile Tabelle §2 anwenden: Länge trimmen → Hook-Sekunden prüfen/neu vertonen → Overlays/Untertitel-Stil anpassen → Sound-Spur tauschen/anpassen
3. Caption + Hashtags nach Tabellen-Spalte NEU schreiben (nie kopieren — Textduplikate sind messbar)
4. Export ohne Wasserzeichen, Dateiname nach Konvention ([[02_Areas/Content_Creation/SOP_Posting_PostProxy|SOP_Posting_PostProxy]] §1)
5. Kit-Eintrag in Notion vervollständigen (alle Pflichtfelder)

## 4. Durchgespieltes Beispiel — 1 Idee, 3 native Fassungen

**Kern-Idee:** „Agent-Log #1: Mein Agent postet meine Videos selbst" (Skript = [[02_Areas/Content_Creation/SOP_Hook_und_Skript|SOP_Hook_und_Skript]] §5 Beispiel A, Master 43 s)

| | YouTube-Short | Instagram Reel | TikTok |
|---|---|---|---|
| Schnitt | 38 s: Beat 3 leicht gekürzt | **28 s:** nur Beat 1+2, Beat 3 wird eigenes Reel (Serien-Split!) | 43 s Vollfassung |
| Hook (0–3 s) | identisch zum Master („Dieses Video wurde von meinem KI-Agenten hochgeladen") | Visual-Hook-Variante (Formel 9): 3 s Screen „Agent legt Post an", Overlay: „Er arbeitet. Ich schlafe." | Master-Hook + Zusatz-Overlay „POV: dein Agent postet für dich" |
| Caption | „Mein KI-Agent postet meine Videos selbst — Setup in 3 Bausteinen. #kiagent #obsidian #produktivität" | „Er hat diesen Post geplant, betitelt und hochgeladen. 🤖\nDie 3 Bausteine: Redaktionsplan → SOP → Auto-Poster.\nWichtig: nichts geht ohne mein Okay live.\nGratis-Template: Link in Bio. #secondbrain #kiagent #studytok #notion #produktivität" | „Er postet. Ich lern für die Klausur. 🤖 Baust du sowas nach? #kiagent #studytok #secondbrain #ai #student" |
| CTA | „Deep-Dive (10 Min) ist auf dem Kanal." | „Gratis-Template → Link in Bio" | „Folg mir — Tag 2 kommt morgen." |
| Sound | Voice only | Voice + dezenter lizenzfreier Track | Voice + nativer Sound leise |

**Ergebnis:** 3 Uploads, die als eigenständige, native Posts wirken — aus EINEM Dreh. Zusatzaufwand gesamt: ~45 Min.

## 5. Sprach-Skalierung (EN-Spur, ab Traktionsphase)

Gleiches Verfahren als 4. Fassung: Skript übersetzen (Modell), neu vertonen (selbst oder KI-Voice → dann KI-Kennzeichnung!), Overlays tauschen, auf SEPARATE EN-Accounts. Erst starten, wenn DE-Kern die Verdopplungs-Regel-Formate gefunden hat ([[02_Areas/Content_Creation/SOP_Content_Engine|Engine §6]]).
