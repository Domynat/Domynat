# Plattform-Spielregeln (YouTube · Instagram/Reels · TikTok)

> **Pflege:** Diese Datei ist die verderblichste des Vaults. Beim Monatsreview ([[02_Areas/Content_Creation/SOP_Content_Engine|Engine]]) kurz prüfen, 1×/Quartal gegen offizielle Quellen (YouTube-Hilfe, TikTok-Support, Meta/IG-Creator-Seiten) verifizieren. Unsicheres ist mit „(prüfen)" markiert.

## YouTube (läuft bereits)

**Formate:** Long 16:9 (Anker, Suche + Session-Time), Shorts 9:16 ≤ 3 Min (Reichweite; optimal 20–40 s).
**Algorithmus-Signale (Rangfolge praktisch):** Klickrate des Thumbnails/Titels (Long) → Ø-Wiedergabedauer/Retention → Session-Fortsetzung (schaut der Nutzer danach weiter?) → Engagement. Shorts: Swipe-Through-Rate (wie viele bleiben statt wegwischen) + Loop/Replays.
**Konsequenzen:** Long-Titel + Thumbnail sind eigene Arbeitsschritte (A/B denken); Kapitelmarken setzen; Shorts-Hook 0–2 s; Playlists/Endscreens für Session-Time.
**Automation/ToS:** API-Uploads sind offiziell erlaubt (YouTube Data API — genau das nutzt Post Proxy); verboten: gekaufte Views/Subs, irreführende Metadaten, „wiederverwendete Inhalte" ohne Eigenanteil (Monetarisierungs-Ablehnungsgrund!).
**Demonetarisierungs-/Sperr-Fallen:** Musik ohne Lizenz (Content-ID-Claim frisst Erlös), massenhaft KI-Voice-Content ohne Mehrwert („inauthentic content"-Policy, seit 2024/25 verschärft (prüfen)), Clickbait-Thumbnails ohne Einlösung (Retention-Tod).
**Kadenz Best Practice:** 3–4 Shorts/Woche + 1 Long/Woche (Anker).

## Instagram (Reels) — neu aufbauen

**Formate:** Reels 9:16 (Kern; **15–30 s beste Reichweite**, bis 60 s wenn dicht; Micro-Serien 30–90 s als Trend (prüfen)), Karussells (unterschätzter Reichweiten-Bringer für How-tos), Stories (Bindung, zählt kaum für Reichweite).
**Algorithmus-Signale:** Watchtime/Abschlussrate → Sends (Weiterleitungen an Freunde = stärkstes Signal!) → Saves → Kommentare → Likes. Reichweite geht überwiegend an Nicht-Follower ("unconnected reach") — jedes Reel ist ein Neukunden-Pitch.
**Konsequenzen:** „Send-würdig" denken (nützlich/witzig genug zum Weiterschicken); Cover-Bild pflegen (Grid = Portfolio); Caption darf länger sein (Save-Trigger: Listen, Steps).
**Automation/ToS:** Posting via offizieller Graph API für professionelle Konten erlaubt (Reels-Publishing unterstützt, Limits ~25–50 API-Posts/Tag (prüfen)); verboten: Engagement-Automation (Auto-Likes/-Kommentare/-Follows), Drittanbieter außerhalb der API.
**Fallen:** sichtbare TikTok-Wasserzeichen (nachweislich reichweitengedrosselt), Engagement-Pods, „unoriginal content"-Downranking bei 1:1-Reposts; Musik: im professionellen Konto nur lizenzfreie/kommerzielle Bibliothek ([[02_Areas/Content_Creation/Compliance_Checkliste|Compliance]]).
**Kadenz:** 3–5 Reels/Woche + 1–2 Karussells; Stories an Posttagen.

## TikTok — neu aufbauen

**Formate:** 9:16; 25–60 s Standard; **≥ 1 Min nur für Creator-Rewards-Qualifikation** ([[02_Areas/Content_Creation/Monetarisierung_Referenz|Referenz]]); Foto-Posts/Slideshows als Zweitformat.
**Algorithmus-Signale:** Abschlussrate/Rewatches → Watchtime der ersten Sekunden (3-Sek-Rate!) → Shares → Kommentare → Follows aus dem Video. Der For-You-Feed testet jedes Video an kleinen Kohorten — die ersten ~200 Views entscheiden.
**Konsequenzen:** Hook noch aggressiver als anderswo; Kommentar-Trigger einbauen (Frage/These); auf Kommentare mit Video antworten (natives Feature, gratis Content); Posting-Zeit an Zielgruppen-Abendzeiten (DE: ~17–22 Uhr) testen.
**Automation/ToS:** Posting via offizieller Content Posting API erlaubt (Post Proxy-Weg); **wichtig: Creator Rewards erfordert PERSÖNLICHES Konto, kein Business-Konto** (prüfen — Kontotyp vor Monetarisierungsantrag checken!); verboten: View-/Follower-Kauf, Massen-Accounts, ungelabelte realistische KI-Medien.
**Fallen:** „Unoriginal content"-Flag bei Wasserzeichen/1:1-Reposts (nicht für dich monetarisierbar), KI-Kennzeichnungspflicht bei realistischen KI-Inhalten, Community-Guidelines-Strikes blockieren Monetarisierungsprogramme dauerhaft.
**Kadenz:** 1×/Tag ideal, 4–5/Woche Minimum fürs Testfenster; Konsistenz schlägt Frequenzspitzen.

## Kanalübergreifende Gesetzmäßigkeiten

1. **Watchtime ist die Währung** — alle drei Plattformen ranken primär nach Halten, nicht nach Gefallen ([[02_Areas/Content_Creation/SOP_Hook_und_Skript|Hook-SOP]] ist deshalb die wichtigste Kreativ-SOP).
2. **Native schlägt identisch:** gleiche Idee ja, gleiche Datei nein ([[02_Areas/Content_Creation/SOP_Repurposing|Repurposing]]).
3. **Konten trennen Arbeit und Monetarisierung:** Vor Programm-Anträgen Kontotyp/Land/Alter prüfen (TikTok persönlich, IG professionell, YT-Kanal verifiziert).
4. **Ein Strike-freies Konto ist ein Asset** — im Zweifel Compliance-Check VOR Upload ([[02_Areas/Content_Creation/Compliance_Checkliste|Checkliste]]), nie „erstmal hochladen und sehen".
